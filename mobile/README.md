# DaSync Mobile

Мобильный клиент DaSync (iOS и Android, один код на Expo / React Native + TypeScript).
Подключается к приложению DaSync на ноутбуке по одноразовому QR и подписывает каждый запрос.

## Запустить на телефоне за 5 минут (без Mac и без платных аккаунтов)

1. Поставь Node.js LTS: https://nodejs.org (на Windows просто «Далее, далее»).
2. Распакуй проект, открой PowerShell в его папке:
   ```
   npm install
   npx expo start
   ```
3. На айфоне поставь **Expo Go** из App Store и наведи камеру на QR из терминала.
   (Ноутбук и телефон в одной Wi-Fi. Если Windows спросит про брандмауэр для Node, нажми «Разрешить».)
4. Открой DaSync на ноутбуке, на главной будет QR. В приложении наведи на него камеру, подтверди запрос в окне DaSync на ноутбуке.

## Что есть в версии 0.1
- Подключение по QR (камера) или вставкой ссылки, подтверждение на ноутбуке
- Тачпад: курсор, клики, правый клик, прокрутка двумя пальцами, перетаскивание
- Экран ноутбука с тапами и режимом Live
- Ввод текста (русский тоже), клавиши, звук и плеер, горячие клавиши, общий буфер обмена
- Обзор: процессор, память, диск, батарея, сеть
- Питание: блокировка, сон, выключение, таймер
- Ключ устройства хранится в Keychain / Keystore
- Если у ноутбука сменился IP, кнопка «Найти в сети»

## Сборка для магазинов (позже)
В `app.json` замени `com.example.dasync` на свой идентификатор (iOS bundleIdentifier и Android package).
```
npm install -g eas-cli && eas login
eas build --platform android --profile preview     # APK для друзей
eas build --platform ios --profile production      # нужен Apple Developer ($99/год)
```
