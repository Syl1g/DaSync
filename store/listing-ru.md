# Google Play: русский (основной язык)

## Название (до 30 символов)
DaSync: пульт для ноутбука

## Краткое описание (до 80)
Тачпад, экран, файлы и мониторинг ноутбука с телефона по домашней Wi-Fi.

## Полное описание (до 4000)
DaSync превращает телефон в пульт для ноутбука. Всё работает напрямую по домашней Wi-Fi: без аккаунтов, без облака, без регистрации.

ЧТО УМЕЕТ
• Тачпад: курсор, клики, правый клик, прокрутка двумя пальцами, перетаскивание
• Экран ноутбука: смотри картинку и кликай прямо по ней, есть режим Live
• Клавиатура: ввод текста (русский тоже), стрелки, Esc, Tab, Enter, горячие клавиши
• Звук и плеер: громкость, пауза, следующий трек, презентации
• Файлы: отправляй фото, видео и документы на ноутбук и забирай файлы обратно
• Буфер обмена: переноси текст между телефоном и ноутбуком
• Состояние: нагрузка процессора, память, диск, батарея, скорость сети
• Питание: заблокировать, отправить в сон, выключить сразу или по таймеру

КАК НАЧАТЬ
1. Поставь бесплатную программу DaSync на ноутбук с Windows: https://syl1g.github.io/DaSync/
2. Открой её, на экране появится QR-код
3. Наведи на него камеру в приложении и подтверди подключение на ноутбуке
Без ноутбука можно посмотреть все экраны в демо-режиме.

БЕЗОПАСНОСТЬ
• QR-код одноразовый и живёт две минуты
• Каждое новое устройство нужно подтвердить на ноутбуке
• Для каждого телефона отдельные права: управление, экран, файлы, питание (питание выключено по умолчанию)
• Каждый запрос подписан ключом устройства
• Никакие данные не отправляются разработчику и третьим лицам
Внимание: связь идёт по домашней сети без шифрования канала. Не используй DaSync в публичных Wi-Fi (кафе, вокзалы).

Нужна программа DaSync на ноутбуке. Приложение работает только в одной Wi-Fi сети с ним.
